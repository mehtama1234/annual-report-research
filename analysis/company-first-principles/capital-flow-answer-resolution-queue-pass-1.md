## Acceptance Standard

Each queue row has to produce one of three outcomes:

- `upgrade`: the missing source proves the mechanism and the claim can move up a level
- `hold`: the source is not found, so the current bounded claim stays unchanged
- `weaken`: the source contradicts the hypothesis or shows the claim was too strong

No answer should be upgraded because it feels likely. The acceptance rule has to be met by a named document, amount, period, actor, mechanism, and boundary.
