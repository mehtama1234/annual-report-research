# MF1 2025-B2 collateral-attribute inventory

Research date: `2026-09-16`

The public MF1 data-procedures exhibit does not disclose or attach the
underlying data tape. It names that file exactly as “MF1 2025-B2 Data Tape
CSR.xlsx,” says it was provided by the company on April 2, 2025, and says it
contained 23 collateral interests and 74 related mortgaged properties as of
April 9, 2025. It also names the fields that were compared or recomputed
against loan files. This turns the next collateral request into an explicit
schema and a specific document-acquisition target.

| Attribute group | Example fields in the public procedure |
| --- | --- |
| Property identity | Address, city, state, ZIP, county, year built, year renovated, property type, specific property type |
| Operating profile | Number of units, unit of measure, occupancy percentage, occupancy date, ownership interest |
| Loan purpose and dates | Loan purpose, note date, first payment date, initial maturity/anticipated repayment date |
| Principal and funding | Original commitment balance, initial funded amount, cut-off-date balance, future-funding advance conditions, balloon balance |
| Rate and protections | Rate type, index, margin, floor, cap, cap termination date, cap provider, rate-cap confirmation |
| Structural terms | Amortization type, ARD flag, extension options, extension requirements, benchmark caps, junior participation terms |
| Credit and collateral | Cross-collateralized/cross-defaulted flag, appraisal source, engineering source, rent-roll source, loan agreement/source file |

The inventory proves that a loan/property-level underwriting schema exists in
the public procedure; it does not disclose values for the 23 collateral
interests or 74 properties, and it does not prove Athene allocation, trustee
remittance, borrower cash, or return. The named workbook is therefore a
high-value next request, but its existence in the auditor's description is not
itself evidence that any collateral balance or cash flow was observed.
