Why:

Accordia has cleaner row-level owned-bond interest-received evidence, but fewer current proceeds events have been column-reconciled. Its best immediate job is disposal-coordinate extraction for matched CUSIPs and issuer resolution for private-marker rows.

## What This Tells Us

In simple words:

`Apollo/Athene has the better next proof chase because it already has named proceeds candidates and mapped issuer/wrapper lanes. KKR/Accordia has strong interest-received evidence, but the next job is still technical: reconcile matched disposal and acquisition event columns before treating event tokens as proceeds.`

The practical sequence should be:

1. Build row-level proof packets for Apollo/Athene AP Aristotle, AMAPS, and Concord first.
2. Keep Eliant, AA Infrastructure, and MF1 as second-wave Apollo/Athene source-availability tests.
3. Run Accordia disposal-coordinate extraction for Intel and Orange.
4. Resolve the Accordia private-marker top-interest issuer `90231*-AA-0`.
5. Only after that, compare liability-cost spread, remittance/waterfall evidence, and return models across the two platforms.

## Why This Matters For The Big-Money Theme

This is where the big-money platform story gets concrete.

A weak version says:

`Apollo and KKR manage a lot of insurance money.`

That is true but not very useful.

The better version asks:

`Which legal entity owned which named asset, how much income or proceeds came back, and what proof still blocks us from calling it cash all the way through?`

This pass answers the selection part of that question.

It does not yet answer the final receipt or return part.
