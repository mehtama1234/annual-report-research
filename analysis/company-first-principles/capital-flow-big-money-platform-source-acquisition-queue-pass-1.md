## Purpose

This pass converts the big-money platform proof chase matrix into a router-specific source acquisition queue.

It asks:

`For BlackRock, Blackstone, Apollo/Athene, KKR/Global Atlantic, Brookfield, Ares, and Carlyle, what is the first document package that could move the platform from map evidence to named cash proof?`

## Short Answer

`The big-router work now has a concrete acquisition queue. BlackRock/HPS and Blackstone need named borrower or project credit files. Apollo/Athene and KKR/Global Atlantic need statutory legal-entity schedules. Brookfield needs a project cash waterfall. Ares/Frontline needs facility documents and borrower cash support. Carlyle needs a named secondaries or credit transaction statement. Until those packages are found, the evidence supports routing maps and bridge claims, not full cash-all-the-way-through proof.`

## What This Queue Means

This is the current end-to-end work path:

`big router -> capital source -> wrapper -> named chase -> decisive document package -> promotion or hold`

The queue says the fastest path to an actual answer is not another broad screen. It is document acquisition against the cases most likely to expose cash movement:

1. Ares/Frontline for private-credit borrower cash.
2. Apollo/Athene and KKR/Global Atlantic for insurance legal-entity cash.
3. Blackstone and BlackRock/HPS for named private-credit or infrastructure borrower/project cash.
4. Brookfield for project-level infrastructure cash.
5. Carlyle for secondaries or credit transaction cash.
6. FPL/PBF/URI/Wheaton/energy as comparison proof patterns.

## Safe Claim

`The big-money platform source acquisition queue identifies the first decisive document package for each major router. It supports execution priority, not proof that platform dollars have already been traced into named borrower/project receipts, legal-entity cash, collateral availability, debt-service waterfalls, or returns.`

## Decision

`big-money-platform-source-acquisition-queue-ready`

The next platform-level work should start with Ares/Frontline facility cash if the goal is the nearest named borrower proof, or Apollo/Athene statutory schedules if the goal is the highest-value insurance-liability proof.
