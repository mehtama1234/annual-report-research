## What Upgrades

This pass upgrades the debt/refinancing lane from denominator visibility to allocation-bridge visibility.

It can now say:

- which rows are refinancing/liquidity bridges
- which rows are treasury allocation and payout coverage bridges
- which rows are reserve-backed source/use/output bridges
- which rows are holdco restructuring bridges
- which row has a named stream funding-to-cash proxy

It still cannot say:

- the financing caused asset-level return
- a specific dollar of debt funded a specific asset unless the source says so
- refinancing produced net value after fees, taxes, market pricing, and risk
- company OCF equals project, refinery, mine, or borrower cash return
