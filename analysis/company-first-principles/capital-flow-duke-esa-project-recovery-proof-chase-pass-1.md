# Duke ESA and Anderson project-recovery proof chase pass 1

Research date: `2026-09-18`

## Purpose

This chase advances Duke's large-load and Anderson County evidence from secured-ESA and project-approval visibility toward customer obligations, project funding, rate-base treatment, and collected cash. It preserves the distinction between load pipeline, approved construction, shared ownership, and common-owner return.

## Required chain

`secured ESA/customer protection -> project and ownership allocation -> approved cost -> construction/CWIP -> in-service plant -> recovery/billing -> collected cash -> debt service and common residual`

## Current conclusion

`duke-esa-anderson-hold-with-approval-and-monitoring-visible`

Duke now has a named approved-and-monitored project plus secured-ESA/customer-protection evidence. The missing proof remains utility/customer allocation, final participation terms, project funding, CWIP/rate-base treatment, in-service billing, and collected cash.
