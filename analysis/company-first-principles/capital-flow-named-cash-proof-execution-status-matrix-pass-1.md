## Proof Rule

A case upgrades only when the same named row joins:

1. capital source or provider
2. instrument or legal channel
3. named destination
4. cash use
5. cash receipt, project cash, borrower cash, or customer billing
6. debt service, legal availability, or settlement/payback
7. return math or earned-return support

The current system has many strong partials, but none yet joins all seven gates.
