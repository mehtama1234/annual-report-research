## Scoring Method

Each lane is scored from `0` to `5` across seven dimensions:

| Dimension | Meaning |
|---|---|
| Source visibility | Can we identify the capital source, wrapper, or funding stack? |
| Use visibility | Can we identify what the capital funded? |
| Output visibility | Can we see physical output, revenue, backlog burn, capacity, cargoes, or service delivery? |
| Cash/recovery visibility | Can we see operating cash flow, debt service, rate recovery, collateral support, spread, or return proxy? |
| Durability visibility | Is the evidence repeated over time rather than one snapshot? |
| Disproof coverage | Have we named the facts that would weaken the claim? |
| Next-proof leverage | Would one or two documents materially upgrade the lane? |

Maximum score is `35`.
