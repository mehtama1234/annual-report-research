# Capital Flow Promoted Claims And Overclaims Pass 1

## Purpose

This page answers:

`What can we safely say now, and what should we not say yet?`

The operating table is:

`analysis/company-first-principles/data/capital-flow-promoted-claims-and-overclaims-pass-1.csv`

This is the writing-control layer for the capital-flow research program.

## Simple Rule

The rule is:

`The sentence we write should match the evidence level.`

A claim can be useful and still not be thesis-grade.

A number can be real and still not prove the broad claim.

## The Main Promoted Claim

The current broad claim we can use is:

`Capital is flowing through different wrappers because the underlying economic claims are different. Some capital funds corporate platforms, some funds legally separable assets, some funds collateral pools, some funds regulated rate-base assets, some funds customer projects, and some funds sponsor-backed acquisitions or refinancings.`

The boundary is:

`We have not yet proven every source-to-use-to-output link across all companies and sectors.`

## Claims We Should Not Say Yet

| Overclaim | Why Not |
|---|---|
| The full capital-flow chain is already proven across all sectors. | We have pieces, not the complete source-to-use-to-output system. |
| Private credit is broadly replacing banks. | We have borrower-level cases and platform evidence, but not lane-matched market displacement proof. |
| Visible BDC fair value equals total borrower debt. | Holder rows are partial slices unless a full facility document reconciles them. |
| Banks are disappearing from corporate lending. | Aggregate and lane-matched bank denominator work is still required. |
| All insurance assets are private credit. | Statutory asset quality and allocation detail remain incomplete. |
| AI demand has created fully funded in-service power assets everywhere. | Utility demand evidence varies by tariff, ESA, docket, approval, construction, and in-service status. |
| Every utility capex dollar is recoverable at attractive returns. | Rate recovery depends on jurisdiction, approval, ROE, lag, and disallowance risk. |
| ET and Cheniere project returns and source-of-funds are fully proven. | Named-project cost, financing source, use allocation, entity waterfalls, customer economics, debt service, and returns remain open. |
| All URI fleet capex is high-return growth capex. | Borrowing-base detail, utilization, fleet mix, and replacement/growth split still need proof. |
| Sterling's backlog is fully customer-funded and risk-free. | Actual post-reset L/C usage, bonded backlog, project-owner funding, margin, cancellation economics, and source-to-project credit allocation are missing. |
| Funding type is proven for every company. | The current map is hypothesis-strengthened, not pattern-proven. |
| Every capex or backlog number equals productive real-economy investment. | Conversion into output, cash, and returns must be shown. |
| A few company examples prove a market-wide capital shift. | Outside denominators are required. |
| A single quarter proves durability. | Time-series proof is still early. |
| The `519` company universe is source-proven or representative of the final thesis. | The template is complete, but most rows still need lane-specific primary-source extraction before empirical coverage claims. |

## How To Use This Register

Before writing a thesis sentence:

1. Find the matching promoted claim.
2. Check the forbidden overclaim.
3. Check the missing evidence.
4. Use the lower-strength sentence unless the promotion test has been passed.
