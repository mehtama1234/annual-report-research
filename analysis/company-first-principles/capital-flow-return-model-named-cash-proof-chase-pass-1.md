## What Would Count As Named Return Proof

A return model only upgrades the row if it joins the money path to the return math:

1. source capital or provider
2. named asset, project, category, fleet class, or borrower
3. use of proceeds or funded cost
4. cash receipts or cash contribution
5. debt service, tax, fees, depletion, depreciation, reserve life, or asset-life cost
6. IRR, NPV, ROIC, earned-return, or lifecycle cash-yield calculation
7. same-period reconciliation to filed statements or regulatory schedules
