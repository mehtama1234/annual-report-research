# Wheaton–Antamina Q-03 next-source package

Research date: `2026-09-18`

## Purpose

Q-03 now proves the contractual debt mechanics and the actual `$1.500B` term
loan draw, but not the executed funds flow, BHP-specific metal-credit receipt,
facility-specific burden, or after-tax financed return. This package turns the
remaining gap into five ranked source requests.

The machine-readable companion is the [Q-03 source-package CSV](data/capital-flow-wheaton-antamina-q03-next-source-package-2026-09-18.csv).

The current quantity-input boundary is preserved separately in the
[Q-03 quantity-proxy note](capital-flow-wheaton-antamina-q03-quantity-proxy-boundary-2026-09-18.md)
and its [structured companion](data/capital-flow-wheaton-antamina-q03-quantity-proxy-boundary-2026-09-18.csv).

## Priority order

1. **Drawdown Notice and designated payee.** The facility is a single closing-
   date draw and permits an irrevocable designated-payee instruction. The
   executed notice is now more valuable than another facility summary.
2. **Agent-to-seller funds flow.** Join the April 1 Wheaton payment and April 2
   BHP receipt to a named agent, seller account, and funding source.
3. **BHP-PMPA credit ledger.** Trace BHP entitlement through metal-credit issue,
   invoice, sale/receivable, and Wheaton bank collection, separately from
   Glencore.
4. **Financing/tax allocation.** Allocate term-loan and revolver interest,
   fees, principal repayment, and Antamina tax; consolidated H1 figures remain
   burden context only.
5. **Reserve-backed return model.** Join delivery duration, threshold step-down,
   ongoing payments, financing, tax, and receipts into a source-linked IRR/NPV.

## Promotion rule

Q-03 can move beyond `evidence-insufficient` only when the source set joins:

`draw -> designated payee -> agent/seller cash -> BHP credits -> sale/receipt -> financing/tax burden -> delivery curve -> return`

The `$1.500B` drawn amount, `$4.300B` upfront payment, combined Antamina cash
surface, and contractual `90%` payable/`100M`-ounce threshold remain useful
controls, but none substitutes for the integrated chain.

## Stop rule

Do not re-run broad searches that only repeat the credit agreement, company-level
debt, combined Antamina OCF, or BHP annual production proxy. Reopen this route
only when a transaction-level funds-flow, BHP-credit, allocation, or
reserve-backed return object becomes available.

## Decision

`return-unproven; source-package-ready`
