# Pilot 03 Apollo–Athene named-asset return routes

Research date: `2026-09-15`

This artifact joins the aggregate Apollo/Athene related-party bridge to three
named statutory asset routes. It is an access-waterfall map, not a claim that
any route has completed cash-to-return proof.

## Access waterfall

```text
Athene liability-funded assets
  -> named statutory holding or CUSIP
  -> cash-like consideration / interest signal
  -> issuer or structured-credit wrapper
  -> borrower/use or collateral destination
  -> trustee/custodian remittance
  -> Athene liability cost and capital burden
  -> Apollo parent collection / distribution
  -> Apollo common-owner cash
```

The first four nodes are now visible for selected routes at different grades.
The last four remain unproven. In particular, a statutory cash-like row is not
automatically a bank receipt, a borrower receipt, an Apollo fee collection, or
a common-owner distribution.

## What this adds to the end-to-end goal

The Apollo/Athene case is no longer only an AUM, spread, and related-party
exposure story. It now contains named issuer/wrapper routes and explicit
document requests for the missing remittance, allocation, liability-cost, and
return steps. The route grades prevent the strongest local candidates from
being silently promoted to full cash proof.
