# Comparison Library Map

Date baseline: 2026-08-12

## What this page is for

The `analysis/cross-sector` folder holds a large set of comparison pages, most created on 2026-08-11. Each one takes a specific angle on the archive's central split: who owns the repeat interface, workflow, or control point, and who carries the heavy labor, assets, debt, or reimbursement burden for the same demand.

There are enough of these pages that a new reader cannot navigate them by filename alone. This page groups them so a reader can go straight to the angle they care about. It does not replace the pages; it indexes them.

If you only want the conclusions, read [what-this-archive-proves-2026-08-12.md](what-this-archive-proves-2026-08-12.md) first. Use this map when you want the detailed company-by-company comparisons behind those conclusions.

## Note on overlap

Many of these pages restate the same core split from a slightly different angle. That is useful for depth but heavy for a reader. Two cleanup items are worth a future pass:

- `relationship-owner-vs-burden-carrier-proof` exists in both a 2026-08-10 and a 2026-08-11 version. The 2026-08-11 version is the fuller rewrite and should be treated as the current one.
- Several groups below (especially "Interface and control vs burden" and "Relationship thickness and habit") contain pages whose distinctions are subtle enough to merge later.
