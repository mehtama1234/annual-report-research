- other threads are covering normal sectors and industries
- this thread is covering what the `AnnualReports` browse tree does not organize well

## New first pass

Use the short [AnnualReports Noncovered Ownership Rule](/home/manishmehta/ui-projects/annual-report-research/indexes/annualreports-noncovered-ownership-rule-2026-08-10.md) before this file when a worker only needs a quick keep-versus-leave screen.

Before claiming a company, test it against one of two top-level cores:

- use the consumer-behavior core first when the best explanation looks like `comfort`, `value`, `routine`, `ritual`, `identity`, or `participation`
- use the infrastructure core first when the best explanation looks like `control`, `access`, or `workflow`

If a company does not fit either top-level core well, that is a signal to be more skeptical about keeping it in this thread.

If a company does fit the infrastructure core and then lands inside one of the mature infrastructure lanes, use the matching extension shortlist before taking it as the next move.

## The decision question

Do not ask:

"is this `AnnualReports` industry page still uncovered?"

Ask:

"is the best explanation for this company one that the `AnnualReports` browse tree expresses badly?"

If the answer is no, leave it to the normal sector thread.

Do not keep a company here just because the live browse-tree page looks thin, outdated, awkward, or sparsely populated.

Thin page quality is not the test.

System-level misclassification is the test.

## Keep in this thread if one of these is true

1. the company materially sharpens a cross-sector system that `AnnualReports` does not organize well
2. the company is more useful for relationship ownership, loyalty, coordination, participation, recurring attention, recurring behavior, or hidden infrastructure than for ordinary industry coverage
3. the formal `AnnualReports` sector or industry is materially weaker than the operating reality
4. the company is needed to complete an existing blind-spot comparison set that already has two or more anchored names in the archive

## Leave to other threads if all of these are true

1. the formal `AnnualReports` category is already a good-enough description
2. the company mainly adds ordinary sector backfill rather than a new system insight
3. removing the company from this thread would not weaken any active blind-spot memo or index
4. the best ownership argument is only that the industry page itself looks incomplete

## The lanes this thread should actively own

- retail as a cross-format system
- marketplace, platform, and coordination systems
- recurring attention and cultural-distribution systems
- travel-interface and travel-marketplace systems
- delivery-layer and demand-routing systems
- DTC control versus channel dependence
- loyalty, wallet, membership, and status mechanics
- fandom, play, collectibles, and participation systems
- beauty, identity, fit, and self-presentation systems
- value-hunt, bargain-discovery, and convenience behavior systems
- routine-use trust, replenishment, and everyday-care systems
- comfort, casualization, and practical-wellness systems
- ritual, occasion, and stimulation systems
- hidden consumer infrastructure behind visible demand
- control-layer and connectivity infrastructure systems
- hidden connectivity and access-layer ownership systems
- physical execution and embedded workflow systems
- modern built-environment systems that cross old sector lines

This is the full blind-spot territory, not a claim that every listed lane is default first-claim work.

The stricter current default is:

- first claim the four core infrastructure lanes
- treat the broader consumer, platform, relationship, and built-environment lanes as conditional unless the subtype gain is clearly stronger than ordinary sector coverage

## The lanes this thread should usually not own

- ordinary upstream materials coverage
- routine industrial backlog stories
- generic utilities
- generic banks and insurers without stronger wallet or relationship-system logic
- straightforward healthcare packetization
- ordinary software or media names with no stronger ecosystem, participation, attention-system, or interface-control angle
- ordinary hardware, telecom, or industrial names with no stronger hidden-infrastructure, access-layer, or embedded-workflow explanation
- plain consumer-brand backfill with no stronger behavioral or channel-control read

## Fast tie-breaker

If a company could fit both this thread and a normal sector thread:

- keep it here when the system-level explanation is clearly stronger
- leave it there when the sector-level explanation is clearly stronger
- if the two explanations are roughly equal, leave it to the normal sector thread and preserve this thread for cleaner blind-spot cases

## One-line operating rule

This thread should own areas where `AnnualReports` has the wrong organizing logic, not merely areas where `AnnualReports` still has incomplete coverage.
