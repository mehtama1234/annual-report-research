## Interface map

| Interface type | Core anchors | What the archive now sees clearly | Best current next move |
|---|---|---|---|
| Membership and utility interface | `Costco`, `Walmart`, `Target`, `Amazon` | paid utility, household repetition, ads, marketplace widening, and convenience-layer thickening | extend only if another name sharpens paid utility or retail-media differences |
| Membership-conditioned wellness interface | `Planet Fitness` | low-friction recurring access, habit-loop wellness, and membership-led body-confidence participation | compare against other recurring-access or low-price habit systems rather than another warehouse or beverage case |
| Marketplace and trust interface | `eBay`, `Etsy`, `Airbnb` | trust, seller or host supply, category culture, and lighter marketplace relationship economics | extend only if another name sharpens trust versus utility versus coordination |
| Local-commerce and fulfillment interface | `DoorDash`, `Instacart`, `Uber` | convenience habit, merchant density, ads, memberships, and physical coordination between app demand and local delivery | extend only if another name sharpens merchant tooling or logistics embedment |
| Fandom and participation interface | `Hasbro`, `Mattel`, `Roblox`, `Take-Two`, `Electronic Arts` | organized play, franchise IP, creator participation, recurrent digital spending, and digital-world identity | extend only if another name adds a genuinely different participation structure |
| Brand-led relationship-control interface | `Nike`, `lululemon`, `Deckers`, `Crocs`, `Levi Strauss`, `Tapestry`, `Abercrombie`, `Victoria's Secret`, `Gap`, `American Eagle`, `Urban Outfitters`, `Birkenstock`, `YETI`, `Warby Parker` | DTC control, brand heat, identity, comfort, fit, and category authority | extend only if another name sharpens weak-middle, lower-price, or service-linked owned-demand structure |
| Value-hunt interface | `TJX`, `Ross`, `Burlington`, `Ollie's`, `Dollar General`, `Dollar Tree` | branded bargains, closeout discovery, neighborhood essentials, and defensive value behavior | extend only if another name sharpens discovery versus necessity value |
| Routine-use trust interface | `Kenvue`, `P&G`, `Colgate`, `Church & Dwight`, `Chewy`, `Coca-Cola`, `General Mills` | replenishment trust, repeat refreshment, efficacy, and digital or channel-mediated routine use | extend only if another name sharpens trust versus healthcare-adjacent care or pantry behavior |
| Ritual and occasion interface | `Starbucks`, `Dutch Bros`, `Monster Beverage`, `Brown-Forman`, `Live Nation` | caffeine habit, stimulation loops, premium occasion demand, and memory-linked spending | extend only if another name adds a distinct ritual-frequency structure |
| Travel and wallet interface | `Delta`, `United`, `Hilton`, `Marriott`, `Booking`, `Expedia`, `Airbnb`, `Carnival`, `Caesars`, `MGM`, `Frontier`, `Southwest`, `Sun Country` | status, trip orchestration, loyalty-funded distribution, wallet continuity, prepaid destination demand, and thin versus thick travel relationships | extend with a payments-linked travel operator or destination-membership counterpoint |

## Highest-priority synthesis extensions

1. Reuse this map when deciding whether a new company belongs in a blind-spot behavior lane or in ordinary sector coverage.
2. Extend into `Financial` only when the goal is to compare consumer routine systems against cards, payments, wealth, or asset-gathering interfaces.
3. Prefer sharpening existing interface boundaries over adding another generic packet to a lane that already has enough anchors.
