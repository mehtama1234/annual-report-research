## Highest-priority archive gaps inside the current framework

1. Direct annual-report artifacts are still missing for several strategically important names:
   `Amazon`, `Nike`, `Costco`, `Walmart`, `Kroger`, `Dollar General`, `Starbucks`, `McDonald's`, `Domino's`, `Caesars`.
2. Standalone transcript coverage is still uneven outside the best-documented names like `Netflix` and `Hilton`.
3. Retail is stronger than before but still needs one more direct Retail company-page packet if the archive is going to claim the current `Amazon` / `Nike` / `Bath & Body Works` split is broadly representative; `Target` and `Burlington` materially improve the retail-like comparison set, but AnnualReports still classifies them under `Services` and `Consumer Goods` rather than formal `Retail`.
4. Consumer Goods now fits the framework conceptually, and Coca-Cola materially improves the routine-beverage lane while Carnival improves the travel lane, but the sector would still benefit from one more name that sharpens either indulgence or wellness behavior.
5. Travel and wallet systems are stronger now that Airbnb and Expedia join Frontier, Southwest, and Sun Country beside Delta, United, Hilton, Marriott, Booking, Carnival, Caesars, and MGM, so the next useful extension is less "another airline or another generic OTA for basic confirmation" and more a payments-linked travel operator or destination-membership system that tests where the relationship layer really sits.
