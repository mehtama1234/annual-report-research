## Highest-priority archive gaps inside the current framework

1. Direct annual-report artifacts are still missing for several strategically important names:
   `Amazon`, `Nike`, `Costco`, `Walmart`, `Kroger`, `Dollar General`, `Delta`, `Starbucks`, `McDonald's`, `Domino's`, `Caesars`.
2. Standalone transcript coverage is still uneven outside the best-documented names like `Netflix` and `Hilton`.
3. Retail still needs another platform or brand-led comparison name if the archive is going to claim the current `Amazon` / `Nike` split is broadly representative.
4. Consumer Goods now fits the framework conceptually, but it would benefit from one more name that sharpens either indulgence, wellness, or routine beverage behavior.
5. Travel and wallet systems would be stronger with one more airline, hotel, cruise, or gaming comparison to test whether the current pattern is mostly a best-operator effect.
