## Highest-priority archive gaps inside the current financial framework

1. Direct AnnualReports company-page HTML artifacts remain missing across much of the financial interface map.
2. Standalone transcript coverage is uneven outside the best-documented alternatives names.
3. The underwriting side still relies heavily on `Chubb`; a second insurer would make the float-and-risk-transfer layer more defensible.
4. The affluent-spend and payments-network side would benefit from another nonbank comparison beyond `American Express`.
5. The market and benchmark infrastructure layer is strong conceptually but would benefit from one more distinct workflow or index-data operator if the project continues broadening.
