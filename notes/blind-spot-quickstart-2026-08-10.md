## First decision rule

Ask:

- does the new browse-tree mandate say this system belongs here?
- is the next task about a system that `AnnualReports` does not classify well?
- does the ownership map say this is one of the system types this thread should own?
- would the short ownership rule keep this name here or send it back to a normal sector thread?

Do not ask:

- is the live industry page thin, awkward, stale, or sparsely populated?

If no:

- leave it to the ordinary sector thread

If yes:

- keep it in this blind-spot lane
- then route it through the relevant top-level core before choosing a company or memo

## Most important scope split

Do not blur these two:

- broad platform boundary:
  `Apple` versus `Netflix` versus `Roblox`
- narrower recurring-attention boundary:
  `Netflix` versus `Spotify` versus `Meta`

If the question is about attention-system subtype, use the recurring-attention materials first.

If the question is about broader ecosystem type, use the platform materials first.
