## What Counts As Real Progress

A run now counts as meaningful only if it does all of these:

- adds missing flagship company roles inside an already-open lane
- converts those packets into sharper lane comparisons
- strengthens existing proof pages with exact company examples and exact period chains
- leaves clearer watch metrics, thesis breakers, and next names for continuation

Collecting filings alone is not enough.

Adding packets without upgrading the lane read is not enough.

Writing abstract insights without naming the packet facts that support them is not enough.

## Required Outputs Per Serious Batch

Each serious continuation batch should leave:

- `4-5` source-complete flagship packets unless the lane structure clearly calls for fewer
- one lane comparison that names the cleaner layer, the burden carrier, the choke point, and the contradiction case
- one proof-page strengthening pass using exact named company evidence
- one watchlist update with exact next metrics and thesis breakers

## Packet Inputs That Must Drive The Writeup

Do not let the lane memo float above the packets.

Every serious lane summary or proof page should visibly use:

- annual report takeaways
- latest three-quarter chain
- plain-English operating model
- strategy read
- growth engine
- main economic lever
- main operating constraint
- exact supporting facts
- burden-versus-beneficiary interpretation
- thesis breaker
- next filing watchlist

If the writeup cannot say which of those fields generated the conclusion, the writeup is still too loose.

## Done Gates

A lane is not done because the companies were covered.

A lane is done only when the repo can show:

1. `what changed`
2. `why it changed`
3. `how we know`
4. `which exact company facts prove it`
5. `who benefits economically`
6. `who carries the burden`
7. `what contradiction case is still alive`
8. `what to watch next that could weaken or break the claim`
